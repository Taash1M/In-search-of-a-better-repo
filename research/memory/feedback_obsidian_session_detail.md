Session logs must have meaningful content in ALL sections (Summary, Key Decisions, Findings & Insights, What Changed, Open Items) — not just the auto-logged tool activity. Write as you go, not in batch at the end.

**Why:** Obsidian is the second brain. The user switches between tools (Claude Code, Codex, other AI) and needs any tool to pick up cold from the session log alone. Empty sections = lost context = wasted time re-investigating.

**How to apply:** After every task block, decision, or discovery, immediately append to the relevant session log section. At session end, review the log and fill gaps. If a section is empty, something was missed. The "What Changed" section is especially critical — paths, URLs, versions, config values. See [[project_obsidian]] for vault structure.
