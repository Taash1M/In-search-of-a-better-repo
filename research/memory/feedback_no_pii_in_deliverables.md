Never include personal names (e.g., "Andy Nguyen", "Taashi Manyanga") or email addresses (e.g., user@fluke.com) in deliverable documents (DOCX, XLSX, PPTX).

**Why:** User explicitly requested removal of all user names and emails from a set of deliverables. Documents may be shared broadly and should reference roles, not individuals.

**How to apply:** When generating any deliverable document, use generic role labels instead of personal identifiers:
- "UBI Admin" / "UBI Admin Team" instead of individual admin names
- "Commercial Americas User" / "Downstream User" instead of specific users
- "Fluke UBI Team" as the author instead of a personal name
- Strip all @fluke.com email addresses — use "—" or omit entirely
- If an email is needed as an example, wrap in "(e.g., ...)" to make it clear it's illustrative, not identifying
